# EvoAtlas · 生命演化图谱

EvoAtlas 是零第三方前端依赖的交互式生命之树工作台。通过时间树、谱系分叉、化石记录和最近共同祖先（MRCA）比较探索亲缘关系，而非构建“低级到高级”的生命阶梯。

> **教学数据集**：当前有 608 个代表性节点、496 个物种节点（新增 461 个现生物种）和原有 5 个灭绝化石类群。所有年代是示意坐标，部分深层拓扑仍有争议，不能把演示内容作为已逐节点验证的科学数据库。

## 功能

- 大画布优先：原生 SVG 系统发育时间树，拖拽、指针锚点滚轮缩放、画布适应与细分/概览视图。
- 类群快速聚焦与中英文/拉丁学名搜索，支持键盘搜索导航。
- 右侧详情：分类路径、概略年代、性状、推荐核验数据库。
- 两个物种的最近共同祖先比较，查看两条后代路径。
- 对数和线性时间坐标、五次主要大灭绝事件的概略标记。
- 浅色 / 深色 / 跟随系统主题；响应式侧栏与移动端详情抽屉。
- 文献与方法入口，明确区分数据建议来源和已核验的节点证据。

## 启动

在仓库根目录运行 Python 静态服务器：

    python3 -m http.server 8000

随后访问 http://localhost:8000 。

推荐使用现代 Chromium、Firefox 或 Safari 浏览器。不需要安装 npm 依赖或构建工具。

## 目录

- index.html：工作台布局
- styles.css：设计变量、浅深主题及自适应样式
- app.js：图谱、比较、搜索与交互逻辑
- data/data.js：原型基础数据（保留历史以利审计）
- data/curation.js：移除生成式占位支系、修正部分关系并补充真实名称类群
- data/species.js：461 个新增现生物种和 38 个分类支系（明确标记待核验）
- data/research.js：研究资料页的数据源与参考链接
- docs/research-notes-2026.md：科学资料、审查边界与设计决策
- scripts/validate_data.py：策展数据结构校验
- scripts/validate_ui.py：页面元素与脚本引用校验
- .github/workflows/validate.yml：GitHub Actions 静态检查

原始文件曾生成 Survey clade 占位节点；运行时由 data/curation.js 全部过滤，正式图谱不再显示这些虚构分类名称。

## 科学表达边界

1. LUCA 不是可确证的第一个生命。图中的根部年代仅为教学示意。
2. 真核起源涉及古菌相关祖先与细菌内共生；根部三域式简图不是唯一被讨论的模型。
3. 化石首次/末次出现范围不能简单等同为谱系起源、灭绝时刻或确定的直系祖先。
4. 此版 ageMa 是示意近似值，而非从 TimeTree 导入的研究级分化时间。
5. 数据字段中的 sources 代表推荐核对的数据库，并不等于逐条核实；confidence 也不是统计上的分支支持度。

**请优先阅读 [研究资料与局限](docs/research-notes-2026.md)。**

## 2026-11 工作台体验更新

- **图谱满铺**：原图谱上方的标题、重复统计、独立“追踪人类谱系”按钮已移除，画布成为中间工作区域的第一层。
- **顶栏面包屑**：当前分类路径放到全局顶栏，可点击任意祖先返回；屏幕较窄时路径可横向滚动。
- **布局准确性**：线性坐标采用等间距的适度刻度，不再套用对数刻度；事件标记保留而拥挤的标签会被省略；节点文字使用候选位置评分避让。
- **下拉菜单一致性**：时间坐标、信息密度及物种比较均使用原生 JavaScript 构建的自定义下拉菜单。底层 select 仍负责表单值和 change 事件，不额外引入运行时依赖。
- **资料目录**：扩展为 18 个研究资源入口，按照名称分类、系统发育、化石地层和补充数据分组，并注明用途及局限；这些仍是外部检索入口，不是实时已接入的数据源。

### 下拉组件和数据资源维护

组件位于 \`ui/custom-select.js\`。运行时调用 \`EvoSelect.enhanceAll()\` 生成弹出列表；程序化设置 \`select.value\` 后需调用 \`EvoSelect.sync(select)\` 或 \`syncAll()\` 更新可见标签。菜单使用 body portal，避免被裁剪，同时支持键盘方向键、Home/End、Enter、Escape、外部点击关闭。

数据源目录位于 \`data/research.js\`。新增条目应包含唯一 code、官方网站链接、所属 group、主要用途、限制以及可访问的数据文档入口。校验方式：

    node scripts/validate_research.js
    python3 scripts/validate_ui.py

**限制：** SVG 图谱当前仍属于教学示意，标签避让只改变文字位置，不改变节点时间坐标或演化拓扑。很大的图仍需要缩放与平移来阅读完整标签。

## 2026-11 物种扩容与下拉图标修复

图谱已补充 **461 个现生物种 + 38 个分类支系**，合计 **608 节点、496 物种**。这些物种使用实际学名，但接受名状态、中文俗名和分类对应关系尚未逐项对照 CoL 正式数据版本。新增记录以 `pending-review` 标注，不能直接作为科研数据使用。

为了保持可读性，「概览」对大型支系使用分层限量展示；「全部节点」可查看当前支系的全部物种。搜索和最近共同祖先比较均使用全量物种目录。物种比较的菜单支持**中文或学名筛选**，避免滚动数百个条目。

下拉菜单的文本 `⌄` 箭头已替换为固定笔画的 SVG 图标；选中项的勾选标记也使用 SVG，消除不同系统字体带来的不一致。

详细名称目录和证据限制见 [docs/species-catalogue.md](docs/species-catalogue.md)。

## 2026-11：大型树图交互优化

针对 608 个教学节点的空间密度和探索体验，主图谱新增：

- **分支折叠提示**：概览中的支系以 `+N` 标示尚未展开的后代数量，点击直接聚焦该支系；节点双击也可聚焦，顶栏面包屑可逐级返回。
- **可导航的小地图**：右下角显示当前图谱拓扑与视口位置，点击或拖动小地图可跳转到其他区域；聚焦缩放时位置同步。
- **谱系路径高亮**：悬停或键盘聚焦节点，沿着已显示的祖先链强调相关连接，其他连线降低对比度。
- **自适应文字密度**：低缩放等级隐藏次要叶节点标签，放大后逐步显示，选中节点始终可见；错位标签用细引导线关联节点。
- **平滑指针缩放与边界约束**：按滚轮增量调整缩放比例，避免突然跳跃和把整棵树完全拖离视区。
- **触控手势**：单指平移，双指以两指中心为锚缩放；可在触控设备上探索细分支。
- **键盘浏览**：节点上方向键向父节点/子节点或兄弟节点移动；Enter 查看，Shift+Enter 深入已选择的支系；小地图方向键移动视口，Home 适应全图。

保留原始树的拓扑和时间示意坐标。小地图和折叠提示是浏览辅助工具，不代表新添加了科学证据或改变了分类推断。

测试：`tests/browser-smoke.cjs` 已增加小地图和分支导航断言，由 GitHub Actions 的 Chromium 工作流执行。

## 布局引擎 V2 — 保留回退的新版树图

树图默认使用布局引擎 V2：`layout/engine.js` 负责子树轮廓、坐标与共享主干；`layout/projection.js` 负责在概览模式安全折叠真实支系。画布仍是零依赖 SVG。

- **布局方式**：在工具栏切换「时间树 / 结构树」。结构树按照层级排布，顶部显示「层级」而不是地质时间；时间树继续支持对数／线性近似年代。
- **多分叉**：例如辐鳍鱼纲的 23 个直接孩子只生成一条共享主干和 23 条横向连接，不再反复描绘重叠竖线。
- **局部展开**：概览中的 `+N` 用于在原位置展开真实支系，`−` 可再次折叠；**双击节点**仍用于聚焦该支系并更新面包屑，不与局部展开混淆。
- **真实路径**：所有可见节点保持 canonical parentId，折叠不改变亲缘关系；搜索结果的祖先路径临时展开。
- **视口位置**：展开／折叠尽可能保持被操作节点的屏幕坐标；现有缩放、小地图与右栏资料仍可使用。
- **旧引擎回退**：访问 `?layout=legacy` 可使用上一代渲染器（结构模式会禁用）；正常页面默认 V2。旧引擎仅作为故障隔离手段。
- **验证**：`node --test tests/layout-engine.test.cjs tests/projection.test.cjs`，以及 Chromium 桌面／移动端冒烟测试。

技术设计和科学表达边界详见 [docs/layout-engine-v2.md](docs/layout-engine-v2.md)。

**仍未完成的研究级能力**：屏幕空间精确文字测量（目前延续候选位置避让）、跨子树增量动画与海量数据虚拟化。此版依旧使用教学型演化拓扑和近似时间坐标。

## 2026-11：科学图谱视觉重新设计

默认改为**结构树**，参考 iTOL 的简洁矩形树与叶端对齐方式：真实末端物种沿同一列排布；可折叠类群通过直观的三角摘要和后代数量表示，点击可原位展开。结构树不显示不适用的年代选项，仍可切换到时间树查看近似时间坐标。

概览节点预算调整为大屏约 36、小屏约 20，并在主要谱系之间轮转分配，避免细菌或其他大型支系占满整张图。标签位置保持稳定，不再反复尝试大幅上下移动；绘制仍基于真实物种 ID 和原始父子关系。原有 `?layout=legacy` 保持可用。

[查看参考案例与设计依据](docs/tree-visual-redesign.md)。此版仍未实施增量动画与万级物种视口虚拟化。
