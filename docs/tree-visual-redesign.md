# EvoAtlas · 生命树可视化重新设计（2026-11）

本次改版聚焦**树图本身**，不以玻璃质感、复杂卡片或装饰动画代替科学可读性。设计依据为公开工具与其文档，而不是复制源码或把截图直接嵌入项目。

## 参考项目和取舍

| 参考 | 有价值的模式 | EvoAtlas 的选择 |
| --- | --- | --- |
| [iTOL](https://itol.embl.de/help.cgi) | 矩形树、叶端对齐、分支折叠成可识别的图形、分叉间距 | 采用矩形结构树作为默认，以及可点击的支系三角摘要 |
| [OneZoom](https://www.onezoom.org/full_guide) | 平滑聚焦、沿支系连续深入、明确的多分叉 | 沿用现有缩放／小地图／搜索，但不把分形枝干做成默认科学图表 |
| [Nextstrain Auspice](https://docs.nextstrain.org/projects/auspice/en/latest/advanced-functionality/view-settings.html) | 结构和时间视图、缩放后的路径与数据层分离 | 将结构树与时间树严格区分；时间信息不会混入结构坐标 |
| [phylotree.js](https://github.com/veg/phylotree.js) | 数据与交互分离、子树折叠 | 继续使用独立纯布局引擎，不追加前端框架依赖 |

## 设计变更

1. **默认结构树（cladogram）**：时间树仍可选择，但默认模式不把未经逐节点核对的演化年代放在图谱主轴。
2. **真实叶端对齐**：只在结构树把真实末端节点对齐到同一列；折叠类群摘要仍保留自身真实层级。节点身份、Y 坐标、父子关系不变。
3. **可点击的折叠三角**：不再只依赖节点下方的小 `+N`，三角形与“类群名称 · N 个后代”直接构成折叠提示。该三角只是视觉符号，并非新增演化事件，也**不表示分化时间**。
4. **标签固定位置**：所有叶端标签位于节点右侧，内部支系标题位于分叉附近；使用 Canvas `measureText()` 对标签估宽，并对非关键重叠标签降低优先级，避免旧版通过上下移动文字修补冲突。
5. **主要谱系轮转展示**：当前概览不再依数据先后顺序，把绝大部分节点预算给某一个支系。新增真实数据契约测试，防止“只看见细菌，看不见真核生物”的情况回归。
6. **更克制的画布**：去除背景密集点阵，降低非重点分支对比度。选中和悬停的祖先路径仍会强调。
7. **阅读操作**：点击三角展开真实子树，悬停出现操作反馈；双击节点聚焦类群，搜索与小地图继续使用。

## 坐标语义与可用性

结构模式按父子层级排列，末端列对齐在 cladogram 语义上是安全的，因为它不声称横向长度对应时间。时间模式依旧按教学近似年代排布，不采用 cladogram 的“强制拉齐末端分支”，以免改变已有时间含义。

高密度局部展开时依然需要滚动和缩放；此版没有假称已经做到千万节点级别的虚拟化。对于持续多叉的真实数据，也不会自动制造二叉祖先改善外观。

## 验收场景

- 全生命树（LUCA）默认概览：细菌、古菌、真核三大支系均可发现，页面不是由一个分支占满。
- 真核生物：植物与后鞭毛生物都应占有可见位置。
- 哺乳纲：猫科等已折叠支系使用三角摘要，点击后原位展开，二次折叠与搜索仍有效。
- 辐鳍鱼纲：23 个直接子节点仍是 1 条共享主干与 23 条独立横线，末端标签沿同一列。
- 时间树：恢复真实时间坐标和灭绝事件标记；与结构模式切换不会改变物种和亲缘关系。
- 移动端与 `?layout=legacy`：旧渲染器仍可回退，触控和菜单保持可操作。

## 下一步仍可优化的内容

- 在缩放停下后增加基于实际 SVG BBox 的文字碰撞微调（当前使用 Canvas 估宽）；
- 展开支系时使用“节点 ID → 位移动画”，支持随时中断、减少突兀重排；
- 为异常高分叉加入更细的视口分段和可检索的分支目录，而不是仅增大 SVG 的总高度。

本次只复用了公开工具的**设计思想**，不复制受版权保护的界面资源、源码或样式文件。


## 2026-11：折叠摘要精简与操作分离

在「结构概览」与「全部节点」下，大量未展示的后代会被表示为一个可展开的摘要控件。旧版的三角形宽约 35–48 SVG 单位、高 18–24，名称和数量混在同一句话中，会抢走主要信息的视觉权重。

新版采用：

- 固定 **12×12** 的小型描边三角，独立于隐藏后代数量，不再因节点数量变化而拉长；
- **类群名称优先，数量为小号低对比度文字**，不使用醒目的数字徽标；
- 整个约 **40 SVG 单位高**的摘要行都可以点击或触控，悬停有轻微背景，键盘有清晰聚焦状态；
- 语义区分：单击节点圆点／普通名称只查看资料，点击摘要行才展开，双击真实节点聚焦到类群；
- 展开后仅在悬停或键盘聚焦时显示分叉旁的小型收起箭头，避免重复的名称或下方徽标占据空间；
- 展开／收起时约 **195ms** 的可中断几何过渡，现有节点移动、新子节点渐入、折叠节点向父类群淡出；设置了 \`prefers-reduced-motion\` 时不做过渡；
- 折叠保留真实 parentId、资料、名称和年代，不把三角或摘要行当作新增物种或推断祖先。

测试覆盖 SVG 图形尺寸、整行命中范围、节点选择与展开的独立性、键盘 Enter 与焦点恢复，以及减少动态效果的行为。
