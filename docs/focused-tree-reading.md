# 逐级浏览：用信息分层取代堆叠

2026-11-23 · 交互设计与实现说明

## 问题背景

旧版的「概览」虽然减少了可见节点数量，但依然将 30 多个分支、折叠三角、时间刻度、节点计数、小地图和图例同时投到画布。固定列对齐只能保证几何规整，不能解决阅读负担。此前反复增加标签字号或间距，常常让其他设备上的布局更拥挤。

## 新的默认交互

默认开启 **逐级浏览**（`detail=focus`）：

- 初次进入最多显示当前类群与少量直接子类群、下一层代表类群（大屏默认最多 12 个节点；手机最多 7 个）。
- 不展示小地图、时间标尺、节点旁三角摘要、底部冗余图例。线条和标签只强调当前范围内真实的亲缘关系。
- 单击查看资料，双击聚焦至该真实类群；标题栏面包屑可逐级回退。
- 对拥有许多直属子节点的支系，如辐鳍鱼纲的 23 项，首屏显示前 7 项，底部标注「本级已显示 7/23 个直属类群」，可展开显示剩余 16 项，必要时再恢复精简。
- 隐藏的是**展示窗口内的真实兄弟条目**，没有新建「其他分支」虚拟分类、没有重新指定其祖先、没有引入新的分化时间。
- 搜索时保留真实祖先路径，深层物种可进入其直接父类群并在图上选中。
- 原「结构概览」和「全部节点」仍在浏览方式下拉菜单中，已有时间树、线性／对数年代轴和小地图均可使用。

## 工程实现

- `layout/projection.js`：新增纯函数 `focus` 投影；输出当前可见节点、直属显示计数和每个节点的未展开后代数。仅返回真实分类节点，保留 canonical parent。
- `app.js`：焦点模式使用紧凑、与页面宽度匹配的横向层级步进。大树仍走原 V2 引擎；只有几何展示缩短，不修改原始数据。子类群以固定文本位置和微弱的次级数量说明呈现。
- `index.html`：浏览方式默认「逐级浏览」，底部只显示当前范围和展开命令；右侧空态改成简洁的操作说明。
- `styles.css`：焦点模式隐藏不适合当前语义的小地图、年代刻度、装饰背景、重复图例。
- 通过 `?layout=legacy` 可继续使用原生时间树回退。
- 数据与科学边界保持原样：演化结构是教学用例，年代近似；某节点拥有多名直属后代并不证明同步多分化事件。

## 验证条件

- 生命共同祖先：默认简洁窗口，无图例与三角，细菌／古菌／真核都能直接读到。
- 哺乳纲：单击查看资料，双击聚焦；页面不需要为了展现全部 158 项缩小文字。
- 辐鳍鱼纲：真实 23 路分叉优先只显示 7 路；「显示其余 16 项」后可看到全部 23 个真实直属节点，随后可恢复。
- 深层搜索：只使用真实父子关系。
- 移动端：更短的视图深度，标签保持可读；手势缩放、菜单、侧栏与上级导航不被改动。
- 切换结构概览／时间树／全部节点：原有功能可用，旧版回退正常。
