# EvoAtlas 产品路线图（2026-11-23 更新）

## 已完成：探索型工作台

- 零前端依赖的 SVG 时间树、类群聚焦、搜索、节点检查器、物种 MRCA 比较。
- 移除装饰型首页 Hero，采用紧凑的三栏科学工作台。
- 浅色/深色/系统主题；移动端导航与详情抽屉；键盘基础操作。
- 清理自动生成的 Survey clade 占位节点；通过策展层补充真实名称的代表性类群。
- 整理数据库、地质标准、真核起源研究入口，并明确教学数据与科学证据之间的边界。
- 引入节点图结构和 UI 静态校验、GitHub Actions CI。

## P0：科学准确性与可验证性

- 给每个节点增加名称来源、版本、外部 ID、文献证据、审核状态。
- 逐条移除/替换原型中的模糊 confidence 标签；时间数据使用原始研究估计区间。
- 将系统发育拓扑与传统分类树解耦。
- 对 LUCA、古菌与真核起源提供模型化的备选关系及文献；不将三域式树视作唯一结论。
- 将化石 occurrence 与 divergence time 分开存储；建立明确的证据视图。
- 明确所有编辑性学名、中文名及分类身份的校验过程。

## P1：数据管线与交互深度

- Catalogue of Life/GBIF 名称版本化快照。
- Open Tree of Life 子树、OTT ID、数据来源差异与未解析多分叉。
- TimeTree 发布版本、分化时间区间、论文 DOI、模型选择。
- PBDB 化石记录与 ICS 地层版本整合。
- URL 分享类群/节点状态、比较历史、树内定位及导出教学图片。
- 可切换的时间标尺、清晰的地质年代区间与事件详情卡片。

## P2：科研与学习工具

- 争议拓扑多版本比较、水平基因转移与内共生关系叠加。
- 关键性状映射、趋同演化、地理分布与地质事件关联。
- 大众学习路线、迷你课程、收藏与笔记；不干扰主图谱的探索体验。
- 多设备可访问性和系统性视觉回归测试。

## P3：大规模渲染（仅在数据规模需要时）

- 数据服务按类群与可见范围裁剪子树。
- 空间索引、聚合/LOD、Worker 布局与增量加载。
- SVG 混合 Canvas 或 WebGL 渲染与可访问的 DOM 覆盖层。
- 如后续组件规模明显增长，再评估 React/TypeScript 迁移；不为重构而强制改写。

## 验收标准

1. 所有数据记录可追溯来源、方法、版本和审核状态；不混入生成占位节点。
2. 任意两物种 MRCA 始终是当前选定拓扑的共同祖先，且结论标注模型边界。
3. 图谱操作无不必要跳页，在低性能设备上仍有合理可读性。
4. 提供可靠的自动化测试和浏览器交互/视觉检查，支持 reduced-motion 和键盘导航。
5. 科学争议得到可见的说明，不用美术效果制造不存在的确定性。
